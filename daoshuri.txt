产品定位：集纪念日管理、倒数日提醒、个性化卡片展示于一体的情感记录工具。用户可创建“盒子”（分组），在盒子内添加多个纪念日子，通过自定义背景、卡片样式、灵活排版，打造独一无二的记忆空间。同时提供完善的数据备份（本地加密、WebDAV）与操作审计日志，保障数据安全。

目标用户：注重仪式感的人群、喜欢记录生活重要时刻的用户、需要管理多个项目/事件倒计时的团队或个人。

二、功能需求详细设计
2.1 核心管理模块
2.1.1 盒子（分组）管理
创建盒子：名称、封面图标（内置图标库+自定义emoji）、默认背景色/背景图（可被内部日子继承或独立）。

盒子排序：拖拽排序、按创建时间/名称排序。

盒子操作：编辑、删除（内部日子一并删除或提醒转移）、归档（隐藏但可恢复）。

2.1.2 日子（事件）管理
每个日子属性：

事件名称

日期（年月日，支持农历选择）

类型：倒数日（未来）/ 纪念日（过去）/ 正计时（已发生天数）

备注文本（支持富文本或仅纯文本）

提醒开关（提前N天通知）

卡片颜色/背景（独立于盒子）

在盒子内添加/编辑/删除日子，支持批量移动至其他盒子。

2.2 个性化与美工设计
2.2.1 背景自定义
颜料盘选择：提供HSB/HSV色盘、RGB滑块、预设主题色（如莫兰迪色系、渐变色）。

自定义上传：本地图库选取图片，支持裁剪、模糊滤镜（高斯模糊0~20级）、暗色遮罩（提升文字可读性）。

全局背景：可设置整个App的统一背景；盒子/卡片支持独立覆盖。

2.2.2 卡片样式与排版
卡片类型：

正方形卡片（1:1）

长方形卡片（宽度:高度 = 2:3 或 16:9，可配置比例）

卡片内容布局：标题+日期+剩余天数/已过天数+装饰元素（小图标、分割线）。

排版网格模式（类似桌面小组件布局）：

1*1：单个卡片占满一行一列。

2*4：每行2个卡片，共4行（横向滚动或固定高度）。

3*3：每行3个，共3行九宫格。

动态流式布局（瀑布流）、行列数可调（如最小列数2~4）。

卡片美化：

圆角半径调节、阴影深浅、边框与描边颜色。

内嵌动效（翻页、渐显、节日特效可配置开关）。

支持卡片背景使用独立的图片/颜色，不跟随盒子背景。

2.3 数据备份与恢复
2.3.1 本地自动备份
首次授权：App启动时或设置中请求“读写本地存储”权限，并弹窗让用户选择一个根备份文件夹（如 Documents/MemoriaBox/Backup）。用户确认后，系统保存该路径到配置，后续不再询问。

自动备份策略：

每次修改数据（添加/编辑/删除日子、盒子、修改卡片设置）后，延迟30秒自动执行增量备份（全量备份也可，视数据量）。

备份文件格式：auto_backup_YYYYMMDD_HHMMSS.db（加密SQLite数据库）。

保留最近10份自动备份，自动删除旧文件。

手动触发全量备份：设置中“立即备份”。

2.3.2 手动本地备份（导出加密文件）
用户点击“导出备份”，弹窗系统文件夹选择器，用户选择目标文件夹。

生成加密文件：memoria_export_YYYYMMDD_HHMMSS.mbox（实际为AES-256加密的zip包，内含数据库+配置文件+图片资源索引）。

可设置导出密码（若不设置，则使用默认固定密钥；建议强制用户设置备份密码）。

2.3.3 导入加密备份文件
点击“导入备份”，弹窗文件选择器，用户选择 .mbox 文件。

输入解密密码 → 验证完整性 → 提示是否覆盖当前数据（或合并模式：智能合并，重复条目跳过或替换）。

导入成功后自动重建数据库并刷新界面。

2.4 WebDAV 网页备份
2.4.1 WebDAV 配置界面
提供一个独立页面，包含以下字段：

WebDAV 服务器地址（如 https://dav.example.com/remote.php/dav/files/username/）

用户名

密码（隐藏输入，可选保存到 Keychain/加密存储）

可选路径子目录（如 /MemoriaBox/）

测试连接：点击按钮发送 PROPFIND 请求，显示“连接成功/失败”及详细错误信息。

提供“保存配置”按钮，将配置加密存储于本地。

2.4.2 上传加密备份
基于当前数据生成加密临时文件（与导出格式相同）。

通过WebDAV PUT方法上传至指定路径，文件名规则 backup_YYYYMMDD_HHMMSS.mbox。

上传进度显示，支持断点续传（可选）。

2.4.3 下载加密备份
获取远程目录文件列表（按修改时间排序），用户选择某个备份文件。

下载到本地临时目录 → 输入密码解密 → 导入数据（与本地导入流程一致）。

下载完成后可选择性保留备份文件到本地。

2.5 数据操作日志（审计日志）
2.5.1 日志记录内容
操作类型：

创建盒子/日子

编辑盒子/日子

删除盒子/日子

访问（查看）具体日子详情（可选记录，用户可开关）

导出/导入备份（加密密码的访问行为，记录“尝试密码”次数与结果，但不明文存储密码）

修改备份配置（WebDAV、本地路径）

日志字段：时间戳、操作类型、目标对象ID与名称、操作结果（成功/失败）、设备标识、App版本。

2.5.2 日志存储与查看
存储在本地加密数据库中，最多保留2000条，超出自动删除最旧。

提供“日志查看”页面，可按类型筛选、按时间排序，支持导出为CSV（加密导出）。

隐私保护：日志不含用户真实密码或敏感内容。

三、技术架构设计
3.1 平台选择
移动端：原生开发（iOS: Swift + UIKit/SwiftUI；Android: Kotlin + Jetpack Compose）或跨平台（Flutter / React Native）。因需求涉及本地文件读写、WebDAV网络请求、加密存储，建议使用 Flutter 提高多端一致性，同时利用平台通道处理特定权限。

数据库：SQLite（通过 sqflite 插件）+ 加密扩展（sqflite_sqlcipher），存储盒子、日子、日志等结构化数据。

本地文件：背景图片、卡片缩略图等存储在应用私有目录，自动备份时复制到用户指定目录。

3.3 加密方案
数据库加密：使用 SQLCipher，密钥由用户首次设置的主密码派生（若未设置则使用设备标识+固定salt，但安全性较低；建议强制要求用户设置App锁密码）。

备份文件加密：AES-256-GCM，密钥由用户提供的备份密码 + 随机salt通过PBKDF2生成。文件结构：[salt(16B)][iv(12B)][ciphertext][auth_tag(16B)]。

WebDAV密码存储：使用Flutter Secure Storage（基于Keychain/Keystore）。

3.4 备份流程细节
本地自动备份
监听数据变更，防抖延迟30秒。

将当前数据库复制到临时文件 → 使用SQLCipher导出明文 → 重新加密使用备份密码（若无备份密码则使用设备唯一密钥）→ 写入用户授权的文件夹。

实现文件夹授权：Android使用 SAF（Storage Access Framework）获取持久化URI权限；iOS使用 UIDocumentPickerViewController 获取书签（security-scoped bookmark）。

WebDAV 交互
使用 dav 协议库或自定义HTTP请求封装：

PROPFIND 列出文件

PUT 上传

GET 下载

支持自签名证书（可选，提示风险）。

3.5 操作日志实现
定义一个全局日志拦截器，在所有核心数据修改方法执行前后记录。

对于加密密码的访问：记录“尝试解密备份”事件，但不明文存储密码哈希，只记录成功/失败及时间。

四、UI/UX 设计建议
4.1 主界面布局
底部Tab栏：盒子（默认）| 卡片广场（展示所有卡片，可按盒子筛选）| 日志 | 我的（设置、备份等）。

盒子列表采用卡片式横向滚动或网格布局，每个盒子显示封面和内含事件数。

点击盒子进入内部，显示该盒子下所有日子的卡片网格，网格布局可在顶部切换（1*1, 2*4, 3*3等）。

4.2 自定义颜色/背景流程
点击盒子或日子的“背景”按钮 → 弹出模态框：色盘（使用 flutter_colorpicker）、图片上传（调用image_picker）、滤镜调节（使用 image 库处理模糊）。

实时预览背景变化。

4.3 卡片编辑器
长按卡片或点击编辑按钮 → 进入卡片样式编辑器，可以调整文字颜色、对齐方式、是否显示农历、背景是否独立等。

4.4 备份与恢复引导
首次进入“我的”页面，若未设置本地备份文件夹，弹出友好的向导页面，解释备份重要性并引导授权。

WebDAV配置提供常见服务商预设（Nextcloud, ownCloud, 坚果云WebDAV等）。
