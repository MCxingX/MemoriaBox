# MemoriaBox 完整功能清单

## 📱 核心功能模块

### 1. 盒子管理 📦
- ✅ 创建/编辑/删除盒子
- ✅ 自定义 emoji 图标
- ✅ 背景颜色/图片设置
- ✅ 高斯模糊 + 暗色遮罩
- ✅ 网格布局切换 (1×1 / 2×4 / 3×3 / Flow)

### 2. 事件管理 📅
支持 5 种事件类型：
- **倒数日** - 显示距离事件还有 X 天
- **纪念日** - 显示已过 X 天
- **正计时** - 从事件开始已过 X 天
- **生日** - 每年重复的生日倒计时，提前 7 天提醒
- **待办** - 任务管理，支持完成状态切换

每个事件支持：
- ✅ 标题 + 备注
- ✅ 农历显示
- ✅ 头像/图片上传
- ✅ 提醒设置 (提前天数 + 具体时间)
- ✅ 闹钟通知
- ✅ 卡片样式自定义

### 3. 日历视图 🗓️
- ✅ 月度日历网格
- ✅ 事件标记点
- ✅ 农历显示
- ✅ 今日高亮
- ✅ 上月/下月切换
- ✅ 点击日期查看当天事件

### 4. 待办清单 ✅

## 📊 数据库结构

### 表清单
| 表名 | 用途 |
|------|------|
| boxes | 盒子信息 |
| events | 事件记录 |
| friends | 好友信息 |
| labels | 标签定义 |
| friend_relations | 好友 - 标签关联 |
| event_labels | 事件 - 标签关联 |
| logs | 操作日志 |

### 实体关系
```
Box (1) ──< Event (N)
Friend (1) ──< FriendRelation (N) ──> Label (N)
Event (1) ──< EventLabel (N) ──> Label (N)
```
