# MemoriaBox 地基重写需求文档

## 背景

MemoriaBox 当前版本 `v3.2.16` 经过多次迭代，积累了功能债务和技术债务：
- `MainScreen.kt` 超过 2500 行，承担过多职责。
- 部分功能通过补丁式修复堆叠，缺乏统一架构。
- 数据层、业务层、UI 层边界模糊，ViewModel 手动实例化工厂。
- 月总结、打字机播放、备份恢复等引擎逻辑混入 Helper 或 ViewModel。
- 桌面小组件未使用 Glance，维护成本高。

用户决定从零重写，以 18 章设计规格为蓝图，搭建稳定、可扩展、可测试的地基。

## 当前地基分析

### 当前优势（保留价值）

| 维度 | 现状 | 评价 |
|------|------|------|
| 数据模型 | 9 个 Entity，覆盖盒子/事件/好友/标签/日记/媒体/日志 | 设计合理，字段完整，可直接复用 |
| 数据库版本 | Room v7，6 个 Migration | 迁移链完整，重写时可从 v1 重新定义 |
| DAO | 6 个接口，Flow + suspend | 查询模式正确，可复用 |
| 事件卡模板 | 6 种模板，支持自定义背景/渐变/文字色 | 用户核心需求，必须保留 |
| 生日逻辑 | 下一年自动计算，当天祝福 | 已修复，逻辑正确 |
| 备份导入 | 合并追加策略 | 数据安全核心，必须保留 |
| 自动备份 | 数据变更触发 onDataChanged() | 已补齐，可复用 |

### 当前问题（必须在重写中解决）

| 问题 | 影响 | 严重度 |
|------|------|--------|
| MainScreen.kt 2500+ 行 | 难以维护、测试和协作 | 高 |
| ViewModel 手动工厂 | 依赖注入不规范，测试困难 | 高 |
| 月总结引擎混入 Helper | 无法独立测试和扩展 | 中 |
| 备份引擎混入 BackupManager | WebDAV、加密、合并逻辑耦合 | 中 |
| 桌面小组件未用 Glance | UI 一致性差，维护成本高 | 中 |
| 缺少 DI 框架 | 所有依赖手动传递 | 高 |
| 缺少 Navigation 类型安全 | 路由字符串硬编码 | 中 |
| 缺少 WorkManager | 自动备份依赖手动触发，不可靠 | 中 |
| 缺少统一错误处理 | 各模块各自 try-catch | 中 |
| 缺少测试框架 | 无单元测试、无 UI 测试 | 高 |

## 重写目标

### 功能完整性

1. 系统 SHALL 保留所有 `v3.2.16` 已有功能，包括盒子管理、事件管理、自定义卡片、生日逻辑、日历日记、好友管理、月总结、备份恢复和桌面小组件。
2. 系统 SHALL 保留底部导航中间项随机颜文字核心交互。
3. 系统 SHALL 保留自定义事件卡模板系统（Hero/Poster/Glass/Split/Neon/Badge）。
4. 系统 SHALL 保留生日当天祝福、生日过后自动计算下一年、普通倒数日不显示生日祝福的逻辑。
5. 系统 SHALL 保留备份导入合并追加策略，不清空旧数据。

### 架构稳定性

1. 系统 SHALL 采用分层架构：UI Layer / Domain Layer / Data Layer。
2. 系统 SHALL 使用 Hilt 进行依赖注入。
3. 系统 SHALL 使用 Navigation Compose 类型安全路由。
4. 系统 SHALL 使用 WorkManager 管理自动备份任务。
5. 系统 SHALL 使用 Glance 实现桌面小组件。
6. 系统 SHALL 为每个 ViewModel 提供 Hilt 注入，不使用手动工厂。
7. 系统 SHALL 将引擎逻辑（打字机、总结生成、备份恢复）独立为可测试的 Use Case 或 Engine 类。

### 可测试性

1. 系统 SHALL 为 Repository 层提供单元测试。
2. 系统 SHALL 为 ViewModel 层提供单元测试。
3. 系统 SHALL 为引擎类提供单元测试。
4. 系统 SHALL 为关键 UI 页面提供 UI 测试。
5. 系统 SHALL 提供测试数据工厂，支持快速构造测试用例。

### 可维护性

1. 每个 Kotlin 文件 SHALL 不超过 300 行。
2. 每个 ViewModel SHALL 只负责一个页面或一个功能域。
3. 每个 Composable SHALL 只负责一个 UI 组件。
4. 所有公共 API SHALL 有 KDoc 注释。
5. 所有数据库变更 SHALL 通过 Migration 脚本处理。
